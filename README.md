# 🛍️ ShopNest — Full-Stack MERN E-Commerce Platform

A modern, responsive, and full-stack e-commerce application built with the **MERN stack**. ShopNest provides a complete online shopping experience with product browsing, authentication, wishlist, cart management, checkout, order tracking, and an admin dashboard.

🔗 **Live Demo:** https://shopnest-ecommercerohit.vercel.app/

🔗 **Backend API:** https://shopnest-dgn4.onrender.com/

🔗 **GitHub Repository:** https://github.com/Rohitkumar968/shopnest

---

## ✨ Features

### 👤 User Features

* 🔐 User registration and secure login
* 🔑 JWT-based authentication
* 👤 User profile management
* 🛍️ Browse and search products
* 🔎 Product filtering and sorting
* 📦 Product details page
* ❤️ Wishlist management
* 🛒 Shopping cart
* 💰 Dynamic cart pricing
* 📋 Order placement
* 📦 Order history
* 🚚 Order status tracking
* 📱 Fully responsive design
* 🌙 Dark mode support

### 🛒 Shopping Experience

* Product categories
* Featured products
* New arrivals
* Product search
* Rating-based sorting
* Category filtering
* Responsive product cards
* Stock-aware product handling
* Clean and modern checkout flow

### 👨‍💼 Admin Dashboard

* 📊 Dashboard analytics

* ➕ Add products

# 🧰 Tech Stack

## Frontend

* React.js
* Vite
* React Router DOM
* Redux Toolkit
* Axios
* Tailwind CSS
* React Icons
* React Hot Toast

## Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcrypt
* CORS

## Deployment

* Vercel — Frontend
* Render — Backend
* MongoDB Atlas — Database
